Drop-in tree models (optional)
------------------------------
Put downloaded tree models here (FBX / OBJ + their textures) and the game uses them
automatically instead of the code-generated trees (80% of trees, the rest stay procedural).
Models are auto-scaled to ~6.5 m tall and placed on the ground.

Free CC0 sources: Quaternius "Textured Lowpoly Trees" (quaternius.itch.io), Kenney "Nature Kit" (kenney.nl).
To go back to procedural trees, delete the files in this folder (keep this README out of Resources if you like).
